# Ilustraciones Arcos

> **Figma:** [Illustrations Guide › Ilustraciones Arcos](https://www.figma.com/design/E0n9VRsdG5TfPRqhf9sbFK/Illustrations-Guide?node-id=6150-3) · componente [`Ilustracion`](https://www.figma.com/design/E0n9VRsdG5TfPRqhf9sbFK/Illustrations-Guide?node-id=7717-660) con 29 variantes de 300 × 300 · relevado vía Figma MCP el 2026-10-16.

Ilustraciones propias de Arcos Dorados, creadas para la nueva web y la App (Rocío Areán y Belén Davis, 2024). Son **un solo componente** con dos propiedades: `Name` (la ilustración) y `Section` (el grupo). Se usan siempre como instancia y se cambia la variante.

Reglas de uso, color y cómo sumar una nueva: [README](../README.md#ilustraciones-arcos).
