# Glosario de traducción

> **Fuente de la verdad:** [Archway Foundations Library (Figma)](https://www.figma.com/design/Us1oNLc2wgmgG3aMuT5dJv/-Archway--Foundations--Library) — página *Colors*, sección **Glosario de Traducción** (última actualización en Figma: julio 2026, 11 términos).
> **Extraído vía Figma MCP:** 2026-10-07.

Términos recomendados para nombrar y documentar ArchWay en español. Los nombres de tokens y propiedades se mantienen en inglés; la documentación y la comunicación con el equipo usan la traducción.

| Término | Traducción recomendada | Notas de contexto |
|---|---|---|
| Leading | Inicio / Inicial | Elemento al principio (ej. ícono a la izquierda). |
| Trailing | Final / Posterior | Elemento al final (ej. ícono a la derecha). |
| Surface | Superficie | Capa o contenedor donde se asienta el contenido. |
| Square | Cuadrado | Forma geométrica. |
| Shape | Forma | Propiedad visual de un elemento. |
| Leading artwork | Arte / Gráfico inicial | Elemento visual situado al comienzo. |
| Hierarchy | Jerarquía | Organización visual de importancia. |
| Feedback | Retroalimentación | Respuesta del sistema ante una acción (ej. un toast o un error). |
| Subtle | Sutil | Algo tenue, como una sombra o una animación suave. |
| Muted | Atenuado | Colores o sonidos de baja intensidad. |
| Trust | Confianza | Principio de diseño para generar seguridad en el usuario. |
| Highlight | Resaltado (atención inmediata) | Categoría de tokens para elementos que requieren atención (notificaciones, novedades). No es decorativo, es funcional. |

> La página dice "11 términos registrados", pero la tabla tiene 12 filas.
