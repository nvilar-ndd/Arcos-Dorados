# Glosario de traducción

> **Fuente de la verdad:** [Archway Foundations Library (Figma)](https://www.figma.com/design/Us1oNLc2wgmgG3aMuT5dJv/-Archway--Foundations--Library) — página *Colors*, sección **Glosario de Traducción** (última actualización en Figma: octubre 2026, 17 términos).
> **Extraído vía Figma MCP:** 2026-10-07 · **Revisado:** 2026-11-16.

Términos recomendados para nombrar y documentar ArchWay en español. Los nombres de tokens y propiedades se mantienen en inglés; la documentación y la comunicación con el equipo usan la traducción.

| Término | Traducción recomendada | Notas de contexto |
|---|---|---|
| Leading | Inicio / Inicial | Elemento al principio (ej. ícono a la izquierda). |
| Trailing | Final / Posterior | Elemento al final (ej. ícono a la derecha). |
| Surface | Superficie | Capa o contenedor donde se asienta el contenido. |
| Square | Cuadrado | Forma geométrica. |
| Shape | Forma | Propiedad visual de un elemento. |
| Leading artwork | Arte / Gráfico inicial | Elemento visual situado al comienzo. |
| Hierarchy | Jerarquía | Organización visual de importancia. |
| Feedback | Retroalimentación | Respuesta del sistema ante una acción (ej. un toast o un error). |
| Subtle | Sutil | Indica algo tenue, como una sombra o una animación suave. |
| Muted | Atenuado | Colores de baja intensidad. |
| Trust | Confianza | Principio de diseño para generar seguridad en el usuario. |
| Highlight | Resaltado (atención inmediata) | Categoría de tokens para elementos que requieren atención (notificaciones, novedades). No es decorativo, es funcional. |

| Inverse | Invertido | Superficie o color que invierte el esquema: oscuro sobre contenido claro (ej. tooltip, toast). |
| Brand | Marca | Color de identidad McDonald's usado como fondo principal (ej. header). |
| Strong | Fuerte | Mayor énfasis dentro de una escala (ej. `Surface/strong`, `Border/strong`). |
| On-color | Sobre color | Texto o ícono que va encima de un fondo de color. |
| Stroke | Borde | Línea de contorno de un componente. |

> Los 5 últimos términos se sumaron en Figma el 13/10/2026 (changelog de *Colors*). La página dice "17 términos registrados", y la tabla tiene 17 filas: la diferencia que había en la versión anterior (11 vs 12) quedó resuelta.
