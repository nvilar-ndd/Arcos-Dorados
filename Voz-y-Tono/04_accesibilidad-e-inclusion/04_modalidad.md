# Modalidades y tecnologías asistivas

No dependas de una única modalidad. Redacta instrucciones que sigan siendo comprensibles si cambia la disposición de la interfaz o si la persona utiliza zoom, navegación por teclado, un lector de pantalla u otra tecnología asistiva.

- Describe la acción, el elemento o la secuencia antes que su posición.
- Evita referencias como “aquí”, “allí”, “arriba”, “abajo”, “a la izquierda”, “en el botón” o “el botón verde” cuando sean la única forma de identificar qué hacer.
- No presupongas que la persona puede ver, oír o realizar un gesto específico para comprender la información.
- Cuando una experiencia use audio, imagen o movimiento, ofrece por otra vía la información necesaria para completar la tarea.

> **Evita**
>
> - Toca el botón de abajo para cambiar el medio de pago.
> - Toca el ícono de lápiz de la derecha.
> - Escucha el mensaje para continuar.
>
> **Mejor**
>
> - Selecciona “Cambiar” para elegir otro medio de pago.
> - Selecciona “Editar” para cambiar la dirección de entrega.
> - Reproduce el mensaje o consulta la transcripción.

Una referencia espacial puede usarse como apoyo si el elemento tiene un nombre claro y la instrucción no depende exclusivamente de su ubicación.

Los emojis no deben sustituir información necesaria. Considera cómo se leen con tecnologías asistivas y consulta la [política de emojis](../03_estilo-de-escritura/14_emojis.md).
