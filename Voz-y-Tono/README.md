# Manual de voz y tono

> **Estado:** carpeta creada el 2026-10-16. Manual en armado.

Cómo habla McDonald's en sus productos digitales de Latinoamérica: App, Web eCommerce, Kioscos (ADK) y Dashboard. Va por fuera de `Archway/` porque no es un sistema de diseño visual: lo usan todos los sistemas y también equipos que no diseñan interfaces (contenidos, marketing, agencias).

## Estructura propuesta

| Documento | Contenido |
|---|---|
| `principios.md` | Personalidad de la marca en producto y los 3–4 principios de voz, con ejemplos de "así sí / así no" |
| `tono.md` | Cómo cambia el tono según el momento: celebración (canje, recompensa), error, espera, ayuda, transacción |
| `canales.md` | Diferencias por plataforma: App (touch, lectura rápida), Kiosco (a distancia, en el local, con apuro), Web, Dashboard (uso interno, operativo) |
| `mercados.md` | Variantes regionales: voseo / tuteo, portugués de Brasil, términos locales (p. ej. nombres de productos y medios de pago) |
| `gramatica-y-estilo.md` | Mayúsculas, números, precios, fechas, horarios, puntuación, inclusión |
| `patrones/` | Microcopy por componente: botones, errores, estados vacíos, confirmaciones, notificaciones, onboarding, formularios |
| `glosario.md` | Términos de producto y su traducción (punto de partida: [glosario de ArchWay](../Archway/Archway-DS/glossary.md)) |

## Cómo se conecta con el resto

- Cada componente documentado en `Archway/` (por ejemplo [Empty state](../Archway/Dashboard/components/empty-state.md)) va a linkear al patrón de microcopy que le corresponde.
- Las reglas de accesibilidad del texto (lenguaje claro, mensajes de error que dicen cómo resolver, textos alternativos) se alinean con WCAG 2.1 AA, igual que el resto del sistema.

## Insumos que necesitamos

- Guía de marca o brand book vigente (si existe una sección de voz).
- Ejemplos reales de copy de la App, del kiosco y del Dashboard, buenos y malos.
- Mercados prioritarios y quién valida cada variante regional.
