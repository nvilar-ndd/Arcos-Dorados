# Mayúsculas

Usa mayúscula solo donde corresponde. Escribe títulos, etiquetas, opciones y demás textos de interfaz con mayúscula inicial y continúa en minúscula. Reserva mayúsculas adicionales para nombres propios, siglas y denominaciones que las requieran.

No uses mayúsculas sostenidas para dar énfasis.

> **Evita**
>
> REVISA LOS DATOS DE PAGO
>
> **Mejor**
>
> Revisa los datos de pago
