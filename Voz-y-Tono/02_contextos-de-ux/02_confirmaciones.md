# Confirmaciones

Las confirmaciones pueden dar certeza sobre una acción que ya ocurrió o ayudar a evaluar una acción antes de realizarla.

## Antes de una acción

Pide una confirmación adicional cuando ayude a prevenir una consecuencia importante o difícil de revertir, no como paso rutinario.

Explica con claridad qué acción está por realizarse y qué consecuencia necesita evaluar la persona. Incluye la información específica necesaria para comprobar que está confirmando la acción correcta.

## Después de una acción

Confirma el resultado principal, incluye los datos necesarios para reconocerlo y explica qué ocurrirá después cuando sea relevante.

Usa una celebración proporcional al momento, sin retrasar la información esencial.
