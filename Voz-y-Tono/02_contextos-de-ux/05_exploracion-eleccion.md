# Exploración y elección

Cuando una persona explora una funcionalidad, un beneficio o varias alternativas, ayúdala a comprender qué se ofrece, reconocer las diferencias relevantes y decidir cómo continuar.

## Facilita comprender y decidir

Presenta primero lo necesario para entender qué puede hacer la persona, qué obtiene o qué cambia entre las alternativas.

- Muestra la información relevante para la decisión actual.
- Conserva las condiciones o consecuencias que puedan cambiar la elección.
- No presupongas que el nombre de una funcionalidad o beneficio explica por sí solo para qué sirve.
- Cuando presentes una funcionalidad nueva o poco conocida, explica qué permite hacer o por qué puede resultar relevante antes de agregar detalles secundarios.
- Evita acumular mensajes o beneficios que compitan con la decisión principal.

La exploración puede admitir cercanía y energía moderada, pero ajusta la expresividad a la importancia de la decisión. No uses entusiasmo, urgencia o presión para desplazar información necesaria para elegir.

## Presenta y compara opciones con foco

Cuando haya varias alternativas, usa denominaciones consistentes y facilita reconocer qué las diferencia.

Prioriza las diferencias que ayudan a decidir. La información secundaria puede quedar disponible como detalle adicional cuando no sea necesaria para comparar las opciones inicialmente.

No agregues atributos solo para que todas las alternativas parezcan tener la misma cantidad de información ni cambies de término para nombrar el mismo concepto.
